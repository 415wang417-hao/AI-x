## ⚡ 一分钟极速上手：零门槛离线查阅 (Zero-Cost Browsing)

**你不需要安装 Python，不需要配置虚拟环境，也不需要连接外网！** 本知识库是一个完全自包含的现代静态门户：

```text
步骤 1：找到当前目录下的 index_zh.html 文件
步骤 2：鼠标双击 index_zh.html（在任意浏览器：Chrome / Edge / Safari / Firefox 中打开）
步骤 3：直接开始探索全套斯坦福 10 周课程、阅读精校中文论文与课件指南！
```

### 💡 核心浏览特性
- **双语一键穿梭：** 在页面右上角点击 `English` 可以毫秒级切换到原汁原味的英文原版主页 `index.html`；在英文版点击 `中文精校版` 即可切回中文。
- **全站本地化无断链：** 所有的课件学习指南、课外必读文献、课后作业手册均已重定向至本地 HTML，支持在无网络离线状态下畅读。
- **原始高清课件直达：** 每份讲义指南顶部均提供了一键打开本地原始高清 PDF 课件的链接（存放于 `slides_pdf/` 目录）。

## 🛠️ 进阶开发者指引：如何复跑与扩展管线 (Pipeline Guide)

如果你需要向本知识库增添新的周次课件、更新翻译术语、或为后续班次增量爬取，请遵循以下开发指引：

### 1. 环境准备 (仅需基础 Python)
本项目依赖极简，仅需本地安装 Python 3.10+ 及两个常见的处理库：
```bash
# 安装轻量级解析与 PDF 依赖
pip install beautifulsoup4 pymupdf
```

### 2. 自动化管线一键复跑
在项目根目录运行主控 CLI：
```bash
# 一键式端到端复跑所有阶段（抓取 -> 提取 -> 翻译 -> QA -> 建站）
python run_pipeline.py --step all
```

### 3. 分阶段独立调试指令
```bash
# 阶段 1：增量同步或校验远端资产 (GitHub 作业 / Slides / Drive)
python run_pipeline.py --step fetch

# 阶段 2：长文本纯文本提取与智能语义分块
python run_pipeline.py --step extract

# 阶段 3：执行术语表强制注入翻译与生成中文页面
python run_pipeline.py --step translate

# 阶段 4：执行自动化质量与断链审计
python run_pipeline.py --step qa

# 阶段 5：静态编译并同步中英双语门户网站
python run_pipeline.py --step build
```

## 🔧 二次开发场景实战指南 (Extension Recipes)

### 场景 A：添加或修改一个专业术语
1. 打开 [`glossary/glossary.json`](glossary/glossary.json)，在 JSON 中加入你的术语定义与规范：
   ```json
   "New Tech Term": {
     "zh": "规范中文译名",
     "definition": "概念释义与技术背景",
     "rule": "排版与翻译规则"
   }
   ```
2. 运行 `python run_pipeline.py --step translate`，流水线将自动把新术语注入全局翻译引擎。
3. 运行 `python run_pipeline.py --step qa` 验证术语在全局文档中的吻合率。

### 场景 B：增加一篇全新的课外推荐阅读
1. 将原始 HTML 保存到 `pages/new-article.html`；
2. 在 `page_map.json` 中登记其原文来源 URL；
3. 运行 `python run_pipeline.py --step extract` 提取纯净 Markdown；
4. 在 `pipeline/3_translate.py` 的字典中配置中文标题与核心内容；
5. 运行 `python run_pipeline.py --step build`，主站导航与本地链接将自动完成挂载与更新。

## ❓ 常见问题排查 (Troubleshooting FAQ)

### Q1: 打开 HTML 页面后排版混乱或缺少样式？
- **解答：** 本项目的中文与英文页面均采用了**完全内联的高性能响应式 CSS**，不依赖任何外部 CDN。只要保证 HTML 文件与同级目录相对结构未被破坏即可正常显示。

### Q2: 想要运行 Week 1 ~ Week 8 的课后实验代码？
- **解答：** 
  1. 进入目标实验目录，如 `cd assignments/week1`；
  2. 查阅本地对应的中文实验手册 [`assignments_zh/week1_assignment_zh.html`](assignments_zh/week1_assignment_zh.html)；
  3. 配置实验环境（推荐使用 Conda 或 Poetry，Python 3.12+），运行 `pytest` 即可直接执行作业自测。

### Q3: 如何验证整套资产是否有断链或破损？
- **解答：** 在根目录下运行 `python run_pipeline.py --step qa`。该脚本会在 1 秒内完成全量 56 份文档的逐行审计，若存在未闭合反引号或不存在的相对链接，控制台与 `reports/qa_report.json` 会精准输出所在文件与行号。
