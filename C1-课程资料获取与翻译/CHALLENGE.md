# Challenge C1：课程资料获取与翻译

> 全量翻译 Stanford Vibe Coding 课程——从获取到翻译到发布，完整的信息获取与处理管线。Phase 1 选拔第一关。

难度：入门 · 建议周期：4 天 · 单人

## 一、挑战定义

Stanford Vibe Coding 课程（2025）是 AI 辅助编程方向的标志性课程。你的任务：**获取课程全部公开资料，组织机器翻译 + 人工校对流水线，产出完整中文课程资料包并发布**。

这考验的不是"会翻译"，而是**信息获取与处理管线**：资料在哪、怎么抓、怎么控制质量、怎么持续更新、怎么让别人用上。

## 二、学习目标

1. 建立完整的信息获取管线：定位一手来源（课程官网 / 讲义 / 视频字幕 / GitHub），批量抓取并归档；
2. 组织"机器翻译 + 术语表 + 人工校对"的翻译流程，产出质量可控的中文版本；
3. 学会用 AI 批量处理长文本：分段、术语统一、格式保持、质量抽检；
4. 以可复用的方式发布成果（GitHub 仓库 / 文档站），让下一批同学零成本复用。

## 三、交付物（required_deliverables）

| 文件 | 说明 |
|---|---|
| `README.md` | 资料包说明：来源、覆盖范围、翻译流程、使用方法、已知缺口 |
| `*AI日志*` | 每日 AI 协作日志：用了什么工具、什么 prompt、踩了什么坑 |
| `*AAR*` | 复盘文件（七维 AAR，见课程模板） |
| `*拿来说明*` | 至少 3 个"拿来说明"：某个关键决策/产出是怎么借助 AI 做出来的（含原文、prompt、产出、对比） |

## 四、验收要点

- 资料包覆盖课程主体内容（≥ 80% 讲义/视频字幕有对应中文）；
- 术语表 ≥ 50 条且全文一致（如 Vibe Coding / Scaffolding / Context Engineering 的译法统一）；
- 翻译流水线可复跑：换一门课的资料，同样的流程能再次产出；
- 发布仓库有完整 README 与目录结构，陌生人可按说明独立使用。

## 五、评分标准（Rubric，100 分制）

| 维度 | 满分 | 要点 |
|---|---|---|
| contentAccuracy 内容准确与完整 | 25 | 覆盖度 ≥80%；术语统一；无大段漏译/机器感硬伤 |
| pipelineAutomation 管线自动化 | 20 | 抓取/翻译/校对流程可复跑、有脚本或清晰步骤；换源可复用 |
| artifactCompleteness 产物完整性 | 15 | README/目录/术语表齐全，仓库可独立使用 |
| aiUsage AI 使用质量 | 20 | 多轮迭代、prompt 优化、质量抽检有据（AI 日志佐证） |
| reflectionQuality 复盘质量 | 20 | 七维 AAR 有实质内容，含失败经验与改进方案 |

**红线**：交付物缺失 → 产物完整性 ≤ 5；无 AI 日志/AAR → 复盘质量 ≤ 5。
